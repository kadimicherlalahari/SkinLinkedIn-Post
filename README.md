# Telegram idea → LinkedIn post

Send a rough idea to your Telegram bot and get back a finished LinkedIn post, written in the voice defined in `skills/meera-pillai-voice/SKILL.md`, generated by Gemini.

No frontend, no database, no dependencies. Needs Node 21.7 or newer.

## Setup

1. Create a bot: message [@BotFather](https://t.me/BotFather), send `/newbot`, and copy the token.
2. Get a Gemini API key from [Google AI Studio](https://aistudio.google.com/apikey).
3. Create `.env` from `.env.example` and fill in `GEMINI_API_KEY` and `TELEGRAM_BOT_TOKEN`.
4. Run `npm start`, send your bot `/start`, and look in the log for `Chat <id>`. Put that id in `TELEGRAM_CHAT_ID` and restart, so only you can use the bot.

The bot polls Telegram, so it only works while `npm start` is running. To keep it up all the time, run it on a server or a process manager such as pm2 or launchd.

## Usage

Send the bot any idea: one line, a messy paragraph, bullet points, a half-finished thought. It replies with only the post, ready to paste into LinkedIn.

If a post needs a figure the idea didn't give, it may contain a `[DATA NEEDED: ...]` placeholder. That comes from the voice skill's rule against inventing numbers. Fill it in before you post.

To test without Telegram:

```bash
npm run generate -- "Most companies don't have a hiring problem. They have a problem explaining why someone should work there."
```

`npm test` runs offline tests. Telegram and Gemini are mocked in them.

## How it works

`src/index.js` long-polls Telegram and passes each message to `src/bot.js`. `src/generate.js` loads the voice skill from disk, builds the prompt (`src/prompt.js`), calls Gemini (`src/gemini.js`), then cleans and validates the result (`src/validate.js`). The finished post goes back to the same chat as plain text.

The voice skill is read fresh on every message, so edits to `SKILL.md` take effect immediately. If it can't be loaded, the bot refuses to generate and logs the error. It never falls back to a generic style. To use a different voice, point `VOICE_SKILL_PATH` at another skill file.

## Configuration

| Variable | Default | |
|---|---|---|
| `GEMINI_API_KEY` | required | |
| `TELEGRAM_BOT_TOKEN` | required | |
| `TELEGRAM_CHAT_ID` | empty (any chat) | Restricts the bot to your chat |
| `GEMINI_MODEL` | `gemini-2.5-pro` | Any Gemini model id |
| `GEMINI_TEMPERATURE` | `0.7` | |
| `VOICE_SKILL_PATH` | `skills/meera-pillai-voice/SKILL.md` | |

Secrets are only read from the environment. They are scrubbed from logs, and the Gemini key is sent in a header, never in a URL. `.env` is gitignored.
